# השוואת קבצי אקסל

אתר להשוואה בין קובץ אקסל **חיצוני** לקובץ אקסל **פנימי** לפי העמודה "מספר פריט".

## שימוש
1. פותחים את `index.html` בדפדפן.
2. מעלים קובץ חיצוני וקובץ פנימי ולוחצים "השוואה".
3. מתקבלות שתי טבלאות — שורות שקיימות רק בחיצוני ושורות שקיימות רק בפנימי (השורה המלאה).
4. אפשר להוריד כל טבלה לאקסל, או קובץ אחד עם שני הגיליונות.

## כללי ההשוואה
- אין הבדל בין אותיות גדולות לקטנות (`ab123` = `AB123`).
- מתעלמים מאפסים לפני האותיות (`0CD5` = `CD5`).
- אפס אחרי האותיות הוא חלק מהמספר (`EF012` ≠ `EF12`).
- מתעלמים מרווחים.
- נקרא הגיליון הראשון בכל קובץ, והכותרות בשורה הראשונה.

הקבצים מעובדים בדפדפן בלבד ואינם נשלחים לשום שרת.
